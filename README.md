# Binary Search Tree & Linked List Merge

A Python implementation of a Binary Search Tree (BST) with both recursive and 
iterative insertion methods, plus a program that merges two sorted linked lists 
into one.

## Features

**Binary Search Tree**
- Recursive and iterative insertion approaches
- In-order traversal with node depth (level) tracking
- Node classification: counts leaf nodes, one-child nodes, and two-child nodes
- Custom `__str__` method for structured, readable tree output

**Linked List Merge**
- Merges two sorted linked lists into a single sorted list
- Accepts user input to dynamically build each list before merging

## What I Learned
This project reinforced recursive tree traversal, pointer manipulation, and the 
tradeoffs between recursive and iterative approaches to the same problem.

## How to Run
python bst_and_linked_list_merge.py
